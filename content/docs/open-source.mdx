SimpleDash is open source under the **AGPL-3.0** license. Every line that touches your Google data is public, so you don't have to take our word for what it does: you can read <SourceRepo>the code on GitHub</SourceRepo>.

## Why open source

SimpleDash asks for access to your analytics. Being open lets anyone check that the access is read-only, that tokens are encrypted, and that no visitor-level data is stored.

## What the license means

You can read, run and change the code. If you run a changed version for other people over a network, the AGPL asks you to share your changes under the same license.

The name "SimpleDash" and its logo aren't part of the license: please don't use them for your own version.

## Report a problem or suggest something

- **Bugs and ideas:** open an issue in <SourceRepo>the GitHub repository</SourceRepo>.
- **Security problems:** email <SupportEmail /> instead of opening a public issue. See [Data and security](/docs/data-and-security#report-a-security-problem).

## Contribute

Pull requests are welcome. The repository's README and CONTRIBUTING files explain how to run it locally. These docs live in the same repository, so you can fix a page with **Edit on GitHub** at the bottom of any page.

## Self-hosting

SimpleDash is built to run simpledash.app. Self-hosting works but isn't officially supported yet: you'd need your own Google Cloud OAuth app, Stripe keys, an email provider and a server.
