SimpleDash uses plain words instead of Google Analytics jargon: "Visitors" instead of "Active users", "Seen" instead of "Impressions". This table maps every word on screen to the GA4 or Search Console name behind it.

## Channel names

| In SimpleDash | GA4's default channel group |
| --- | --- |
| Direct | Direct |
| Search | Organic Search |
| Social | Organic Social |
| Other sites | Referral |
| Email | Email |
| AI assistants | AI Assistant |
| Video | Organic Video |
| Shopping | Organic Shopping |
| Search ads | Paid Search |
| Social ads | Paid Social |
| Display ads | Display |
| Other ads | Paid Other, Cross-network and other paid channels |
| Unknown | Unassigned |
