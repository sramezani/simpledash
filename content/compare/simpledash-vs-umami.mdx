Both are open source, but they solve different problems. **Umami** is a tracker: you add its script (to your own server or its cloud) and it replaces Google Analytics. **SimpleDash** is a dashboard: it reads the Google Analytics 4 data you already have and shows it on one page.

## Side by side

|                                            | Umami                       | SimpleDash                |
| ------------------------------------------ | --------------------------- | ------------------------- |
| Tracking                                   | Its own script              | None: reads your GA4      |
| Hosting                                    | Self-host, or Umami's cloud | Hosted at simpledash.app  |
| Open source                                | Yes                         | Yes (AGPL-3.0)            |
| Your existing GA4 history                  | Not read                    | Read directly             |
| Live visitors                              | Yes                         | Live count and live globe |
| Public stats page                          | Share links                 | Yes                       |
| Search Console and Stripe on the same page | No                          | Yes (Pro)                 |
| Weekly email                               | Check Umami's site          | The Monday email (Pro)    |

Check [Umami's site](https://umami.is) for its current plans and features.

## Choose Umami if

you want to own your analytics data on your own server and leave Google Analytics, and you're comfortable running it.

## Choose SimpleDash if

you want to keep GA4 (free, with its history) without running anything yourself, and want a simple page, a Monday email and a public stats page.
