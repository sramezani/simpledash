The difference is simple: **Plausible replaces Google Analytics** with its own lightweight, cookie-free script, while **SimpleDash keeps Google Analytics** and shows your GA4 data on one simple page. Choose Plausible if you want to leave Google; choose SimpleDash if you already run GA4 and want it to be readable, with your history.

## Side by side

|                           | Plausible                         | SimpleDash                               |
| ------------------------- | --------------------------------- | ---------------------------------------- |
| Tracking                  | Its own script                    | None: reads your GA4                     |
| Cookies                   | Cookie-free                       | GA4's (with your consent banner)         |
| Your existing GA4 history | Can import it                     | Read directly                            |
| Open source               | Yes                               | Yes (AGPL-3.0)                           |
| Self-hosting              | A community edition               | Not officially supported yet             |
| Simple dashboard          | Yes                               | Yes                                      |
| AI assistant traffic      | Shown as sources                  | A dedicated card                         |
| Public stats page         | Yes                               | Yes                                      |
| Weekly email              | Yes                               | The Monday email (Pro)                   |
| Search Console            | Yes, can be connected             | Yes, with five views (Pro)               |
| Revenue from Stripe       | Through goals with revenue values | Stripe revenue, MRR, new customers (Pro) |
| Free plan                 | No (a trial)                      | Yes, all your sites                      |

Check [Plausible's site](https://plausible.io) for its current plans and features.

## Choose Plausible if

- you want to stop using Google Analytics,
- you want cookie-free analytics that may not need a consent banner in some places (check your own rules),
- you want a light script and data hosted in the EU.

## Choose SimpleDash if

- you already run GA4 and want to keep it (it's free, and your history is there),
- you want a simple view without adding a second script to your site,
- you want GA4, Search Console and Stripe on one page (Pro).

## Can I use both?

Yes. Some people run Plausible's script alongside GA4. SimpleDash would show the GA4 side. The two will show different numbers, because they count differently. [Why numbers differ](/guides/ga4-numbers-differ).
