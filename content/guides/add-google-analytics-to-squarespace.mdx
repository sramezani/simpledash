Squarespace has a setting for Google Analytics: open **Settings → Developer tools → External API keys**, paste your GA4 Measurement ID (`G-…`) into the Google Analytics field, and save. On plans with code injection, you can paste the full Google tag instead.

## Add your Measurement ID

<Steps>
<Step>

In Squarespace, open **Settings**, then **Developer tools** → **External API keys**. (On older versions, look under Settings → Advanced → External API keys.)

</Step>
<Step>

Paste your Measurement ID, which starts with `G-`, into **Google Analytics account number**.

</Step>
<Step>

Choose **Save**.

</Step>
</Steps>

## Or: code injection

On plans that include it, paste the full Google tag in **Settings → Developer tools → Code injection → Header**. Use one method only, or visits are counted twice.

## Check it works

Open your site in a private window (not logged in) and GA4's **Realtime overview**. [More ways to check](/guides/check-ga4-is-working).

<InSimpleDash>
  Sign in to SimpleDash with the same Google account to see your Squarespace site's visitors,
  sources and top pages on one page, in plain words.
</InSimpleDash>
